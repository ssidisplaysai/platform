# GBA-0005 Sales Dashboard

## Dashboard Metrics
- Total Pipeline Value
- Weighted Forecast
- Win Rate
- Cycle Time (days)
- Account Risk Score
- Fulfillment Readiness
- Recommendation Count

## Inputs
- Sales pipeline, forecast snapshots, account intelligence, recommendation stream.
- Cross-agent readiness signals from Operations and Manufacturing.
- Canonical GED entity coverage checks.

## Determinism
Dashboard lineage is generated via stable checksum over metric inputs.
