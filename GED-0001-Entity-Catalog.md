# GED-0001 Entity Catalog

## Catalog Summary
The canonical catalog contains 39 shared enterprise entities.

| Category | Entities |
|---|---|
| Enterprise Foundation | Organization, Business Unit, Facility, Department, Employee, Role |
| Commercial | Customer, Contact, Vendor, Supplier, Product, Product Family, Service, Project, Opportunity, Quote, Sales Order |
| Operations | Purchase Order, Work Order, Manufacturing Order, Inventory Item, Warehouse, Asset, Machine, Vehicle, Shipment |
| Finance and Legal | Invoice, Payment, Contract, Subscription |
| Knowledge and Governance | Document, Knowledge Artifact, KPI, Goal, Recommendation, Risk, Approval, Task, Event |

## Canonical Model Rules
1. Each entity has one canonical key.
2. Each entity has one stewardship area.
3. Each entity has one lifecycle preset.
4. Each entity is available to all required Business Agents as a shared contract.
