# 07 Condition Closure

## Purpose

Close certification conditions through targeted, minimal, ownership-neutral remediation and independent re-verification.

## Trigger

A prior certification issued conditions that are open and actionable.

## Workflow

1. Confirm which conditions are already resolved and which remain open.
2. Create focused work orders for each ownership domain.
3. Add explicit negative-path or gap-closing evidence.
4. Apply only minimal implementation changes required by evidence.
5. Re-run full required validation suite.
6. Produce condition closure package and decision.

## Example from proven chain

1. GBM-0001 closed shared baseline conditions C01/C02.
2. GKN-1001B closed platform-specific C03 through explicit negative-path assurance.

## Entry criteria

1. Conditions are clearly enumerated.
2. Ownership of each condition is clear.
3. Scope constraints are declared.

## Exit criteria

1. Each addressed condition has pass/fail evidence.
2. Full required validation passes.
3. Closure decision is explicit: RESOLVED or REMAINS OPEN.

## Success criteria

1. No hidden condition carry-over.
2. No scope expansion while closing conditions.
