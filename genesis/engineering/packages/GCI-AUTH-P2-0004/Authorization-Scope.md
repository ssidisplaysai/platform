# Authorization Scope

## Authorized Scope
- deterministic rule evaluation over Entity and Relationship outputs
- deterministic calculations and validations
- eligibility evaluation
- compliance evaluation
- policy evaluation
- derived facts
- reproducible outcomes
- rule identity and versioning
- rule lineage and provenance preservation
- replay linkage, evidence linkage, and certification linkage
- append-only lifecycle management
- deterministic registry behavior

## Explicit Non-Scope
- Business Genome Assembly Runtime
- genome compilation
- persistence
- scheduling
- queues
- workers
- deployment
- infrastructure
- database ownership
- message buses
- workflow execution
- AI, LLMs, machine learning
- probabilistic reasoning
- heuristics
- inference
- OCR
- crawlers
- conflict resolution outside deterministic rules
- runtime mutation
- side effects
