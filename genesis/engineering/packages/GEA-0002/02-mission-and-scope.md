# 02 Mission And Scope

## Mission
Define a constitutional compiler architecture that can answer:
1. What evidence is discoverable.
2. What evidence is authoritative.
3. Which entities and relationships can be proven.
4. Who owns each extracted entity.
5. Which constitutional authority governs each entity.
6. What lineage exists from constitutional authority through release and certification.
7. Which relationships are authoritative, derived, potential, or unknown.
8. How deterministic output is guaranteed.
9. How missing, conflicting, and ambiguous inputs are handled.

## Scope
1. Architecture for repository discovery, parsing, extraction, graph assembly, validation, and emission.
2. Architecture for diagnostics, drift detection, and freeze-readiness assessment.
3. Architecture for indexes enabling navigation, query answerability, and impact analysis.

## Out Of Scope
1. Compiler runtime implementation.
2. Parser implementation.
3. Atlas UI implementation.
4. API implementation.
