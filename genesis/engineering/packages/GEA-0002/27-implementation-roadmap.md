# 27 Implementation Roadmap

## Distinction Of Artifacts
1. Atlas specification: GEA-0001.
2. Compiler architecture: GEA-0002.
3. Compiler implementation: future engineering program.
4. Compiled Atlas dataset: future generated output from implementation.
5. Atlas UI: future consumer layer, outside GEA-0002 scope.

## Roadmap Phases
1. Phase A: metadata contract hardening across certified packages.
2. Phase B: parser and extractor implementation with deterministic test harness.
3. Phase C: graph construction and validation engine implementation.
4. Phase D: output index generation and diagnostics implementation.
5. Phase E: governance-grade certification and freeze-readiness operations.

## Governance Notes
1. Completion of GEA-0002 architecture does not certify GEA-0001.
2. GEA-0001 remains rejected for freeze until evidence-backed instantiated Atlas mappings are produced and reviewed.
3. Any status reconsideration requires formal governance review.
