# 03 Compiler Principles

1. Constitution-first processing: all interpretation is authority-scoped.
2. Evidence before inference: no authoritative claim without certified evidence.
3. Determinism by contract: identical certified inputs produce identical outputs.
4. Fail-closed for constitutional, ownership, certification, and authoritative relationship claims.
5. Boundary preservation: platform and application ownership boundaries remain explicit.
6. Traceability-first: each node and edge includes provenance fields.
7. Classification transparency: authoritative, derived, potential, unknown are machine-readable.
8. Additive architecture: no redesign of frozen foundation artifacts.
