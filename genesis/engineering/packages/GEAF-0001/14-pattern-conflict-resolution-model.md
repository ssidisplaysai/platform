# 14 Pattern Conflict Resolution Model

## Conflict Types
1. Scope conflict: a pattern appears both framework and application-specific.
2. Authority conflict: downstream artifact appears to redefine upstream law.
3. Boundary conflict: recommendation implies implementation behavior.

## Resolution Process
1. Validate source authority level.
2. Apply non-redefinition rule.
3. Apply implementation-independence rule.
4. Assign pattern to lowest valid ownership layer.
5. Record rationale in traceability matrix.

## Default Resolution
When unresolved, classify as application-specific and block promotion to Genesis-owned framework until governance review decides otherwise.
