# 03 Reusable Pattern Catalog

## Universal Reusable Patterns

1. Constitutional precedence before implementation.
2. Deterministic lifecycle transitions with explicit gates.
3. Immutable publication boundaries and append-only evidence.
4. Acyclic dependency law with no upward coupling.
5. Architecture-stage separation from implementation realization.
6. Full traceability from authority source to derived artifact.
7. Explicit non-responsibility declarations per layer.

## Genesis-Owned Patterns

1. Constitutional Services program layering and milestone sequencing.
2. Governance model with review/correction/approval/freeze/supersession states.
3. Runtime foundation freeze semantics and extension-only governance.
4. Business Genome compiler pass ordering with provenance guarantees.
5. Canonical layer-domain-family mapping from GAF-0001.

## Application-Specific Patterns (Retained Outside Genesis)

1. STONER semantic dictionary contents.
2. STONER ownership mappings for domain entities.
3. STONER policy/rhythm/application constitution sequencing.
4. Any business-specific object vocabulary and rules.

## Catalog Intent
GEAF reuses architecture method, governance structure, and boundary law; it does not inherit application business semantics.
