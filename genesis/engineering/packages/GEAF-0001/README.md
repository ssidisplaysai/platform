# GEAF-0001 Package

This package captures GEAF-0001: Genesis Enterprise Architecture Framework.

Purpose:
- Extract reusable architecture patterns from certified Genesis artifacts.
- Partition patterns into universal reusable, Genesis-owned, and application-specific domains.
- Preserve architectural boundaries: no runtime redesign, no compiler redesign, no application business logic absorption.

Constraints:
- Architecture only; no implementation.
- GSTP artifacts are read-only inputs and were not modified.
- No commits, tags, or release mutation actions are performed by this package.

Primary evidence sources are listed in 02-evidence-sources.md.
