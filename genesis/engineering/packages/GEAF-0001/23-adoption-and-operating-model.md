# 23 Adoption And Operating Model

## Adoption Model
1. Use GEAF universal patterns as default architecture guardrails.
2. Use Genesis-owned patterns for Genesis program architecture decisions.
3. Keep application-specific semantics in application constitutional packages.

## Operating Model
1. Evidence-first synthesis.
2. Governance-gated classification.
3. Boundary enforcement before recommendation publication.
4. Traceability update after every architecture decision.

## Success Criteria
- Reduced architectural drift.
- Clear ownership boundaries between Genesis framework and application domains.
- Review-ready, evidence-backed recommendations.
