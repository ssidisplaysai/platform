# 06 Governance And Authority Model

## Authority Sources
- Genesis Constitution (as declared by GAV-0001 and GAF-0001).
- Framework authority in GAF-0001.
- Constitutional Services program authority in GCSA-PROGRAM-0001.
- Runtime freeze authority in AFR-0004.

## Governance Flow
1. Vision defines enduring doctrine.
2. Constitution and framework define structural law.
3. Program architecture defines milestone sequencing and lifecycle controls.
4. Reviews certify conformance and readiness.
5. Freeze records preserve immutable baseline boundaries.

## Governance Controls
- Review and correction loop.
- Explicit lifecycle states.
- Freeze and supersession controls.
- Dependency legality gates.
- Traceability evidence requirements.
