# 08 Terminology Governance

## Canonical Terms
- Constitutional authority
- Dependency law
- Lifecycle state
- Freeze
- Supersession
- Determinism
- Provenance
- Lineage
- Traceability
- Implementation independence

## Prohibited Drift
- Do not treat framework as implementation spec.
- Do not treat application vocabulary as framework vocabulary.
- Do not reinterpret runtime freeze as optional guidance.

## Reserved Naming
- Genesis-wide standards and governance identifiers remain in Genesis namespaces.
- Application identifiers remain application-owned.
