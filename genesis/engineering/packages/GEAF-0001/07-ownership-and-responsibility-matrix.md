# 07 Ownership And Responsibility Matrix

| Domain | Owns | Does Not Own |
| --- | --- | --- |
| GAF Framework | Layer/domain/family law, dependency law | Runtime algorithms, APIs, deployment |
| GCSA Program | Service governance architecture and milestone sequencing | Runtime behavior, compiler algorithms, implementation contracts |
| Runtime Foundation | Deterministic execution substrate contracts | Application business semantics |
| Business Genome Compiler Architecture | Evidence-to-genome transformation contracts | Blueprint projection ownership, runtime generation |
| GEAF-0001 | Pattern extraction and partitioning | STONER business logic or application constitutions |

Ownership decision rule: when ambiguity exists, retain ownership with the lower-level domain that contains business meaning, not with the framework layer.
