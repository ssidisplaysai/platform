# 04 Pattern Partition

## Partition Decision Model
- Universal: transferable to non-Genesis contexts without constitutional namespace dependency.
- Genesis-owned: requires Genesis constitutional authority, artifact taxonomy, or lifecycle semantics.
- Application-specific: tied to a specific enterprise domain or product constitution.

## Partitioned Results

### Universal
- Dependency acyclicity.
- Deterministic transformations.
- Traceability and reviewability.
- Governance-gated lifecycle progression.

### Genesis-Owned
- GAF layer/domain/family structure.
- GCSA milestone architecture and governance controls.
- AFR runtime freeze and extension constraints.
- Genesis compiler stage contracts tied to Genesis standards.

### Application-Specific
- STONER enterprise semantic contracts and domain dictionary.
- STONER constitutional object ownership details.
- STONER program-specific governance rhythm details.

## Enforcement Rule
If a pattern requires STONER-specific terms for correctness, it is application-specific and cannot be absorbed into GEAF constitutional framework ownership.
