# 05 Lifecycle Model

Lifecycle controls:
- DRAFT -> ACTIVE/ARCHIVED
- ACTIVE -> INACTIVE/SUSPENDED/ARCHIVED
- INACTIVE -> ACTIVE/ARCHIVED
- SUSPENDED -> ACTIVE/ARCHIVED
- ARCHIVED -> terminal

Lifecycle evidence:
- Transition mismatch and invalid transition rejection.
- Lifecycle transitions recorded in organization lifecycle history.
- Lifecycle metrics and audit events produced on status change.
