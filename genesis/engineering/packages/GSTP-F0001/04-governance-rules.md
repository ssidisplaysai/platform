# Governance Rules

1. No implementation package may redefine philosophy.
2. No application may redefine enterprise architecture.
3. No runtime implementation may redefine application constitutions.
4. All engineering packages inherit governance from architecture.
5. Architecture changes require constitutional review.
6. Philosophy changes require executive approval.
7. Every implementation package must trace to:
   - Manifest
   - Constitution
   - Enterprise Architecture

## Enforcement
- Violations are blocking findings in architecture or engineering review.
- Exceptions require explicit authority decision and traceable impact analysis.
