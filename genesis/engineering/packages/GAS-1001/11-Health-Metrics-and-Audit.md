# 11 Health Metrics and Audit

Health checks include:

- persistence
- registry
- versions
- integrity
- relationships
- collections
- lifecycle
- retention

Metrics include:

- asset totals by lifecycle
- version totals
- checksum verification count
- integrity failure count
- relationship and collection counts
- retention-protected asset count
- audit event count
- recovery and corruption counters

Audit model:

- Append-only records for registration, versioning, metadata, lifecycle, retention, integrity, relationship, and collection operations
