## Deterministic Lookup Paths
### Lookup by package identifier
- Open package catalog and find `Identifier` row.
- Read `Governing Program` and `Dependencies`.
- Follow `Successor Packages` for progression.

### Lookup by implementation stream
- Open implementation relationship map.
- Resolve governing constitutional architecture.
- Confirm certification and audit references.

### Lookup by certification/audit posture
- Open certification index for disposition pathway.
- Open audit index for completed baselines and active references.

## Navigation Guardrails
- Use package identifiers as canonical anchors.
- Never infer authority from implementation files alone.
- Resolve architecture intent before interpreting runtime behavior.
