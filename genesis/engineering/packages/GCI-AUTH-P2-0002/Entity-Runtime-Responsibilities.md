# Entity Runtime Responsibilities

The Entity Runtime is responsible for converting immutable IBR identity observations into governed, deterministic entity records.

Authorized responsibilities:
- canonical entity candidate formation;
- identity observation grouping;
- alias normalization and alias retention;
- duplicate and near-duplicate candidate handling;
- confidence and contradiction preservation;
- provenance and lineage recording;
- lifecycle transitions, versioning, supersedence, and retirement;
- immutable registry snapshot behavior;
- focused engineering evidence support.

These responsibilities are bounded by deterministic, contract-only inputs and must not infer facts without governed evidence.
