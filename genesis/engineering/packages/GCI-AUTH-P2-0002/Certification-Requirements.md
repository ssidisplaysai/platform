# Certification Requirements

Independent certification for the later Entity Runtime implementation must verify:
- deterministic entity identity;
- repeatable candidate formation;
- immutable entity records;
- alias determinism;
- duplicate and near-duplicate handling;
- contradiction preservation;
- unresolved identity handling;
- reproducible confidence calculation;
- version lineage, supersedence, and retirement;
- replay linkage;
- IBR linkage;
- certification linkage;
- registry overwrite semantics and ordering;
- negative-path integrity;
- architecture guardrails;
- Replay and IBR regression safety;
- package/catalog integrity;
- clean isolated candidate snapshot.
