# Authorization Scope

## Authorized Scope
The Entity Runtime may deterministically:
- consume IBR identity observations;
- group compatible observations;
- form canonical entity candidates;
- assign stable entity identifiers;
- preserve aliases, contradictions, confidence, provenance, and lineage;
- version entity records;
- model supersedence and retirement;
- maintain deterministic registry behavior.

## Unchanged Scope
The authorization does not alter any upstream runtime contract and does not add new rights to other Phase 2 semantic runtimes.

## Explicit Exclusions
This authorization excludes canonical relationships, rule execution, genome assembly, persistence, orchestration, scheduling, deployment, and inference beyond governed evidence.
