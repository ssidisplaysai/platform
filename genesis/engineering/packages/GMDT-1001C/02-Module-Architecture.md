# 02 Module Architecture

| Module Family | Purpose | Public Surface | Internal Surface | Aggregate Boundary | Dependency Direction | Consistency Boundary | Shared Integration | Foreign Contract Dependencies | Prohibited Cross-Module Access |
|---|---|---|---|---|---|---|---|---|---|
| contracts | bounded platform contracts and type shapes | command/query DTOs, external reference contracts, validator interfaces | contract mappers and adapters | none; contracts are boundary-only | consumed by domain, services, integration | contract schema validity | schema validator, common validators, version utilities | Product, Inventory, Document, Knowledge, Asset, Finance, Commerce references | direct foreign persistence access |
| domain | Manufacturing entities, value objects, aggregates, invariants | domain factories, aggregate roots, invariant helpers | state transitions, lifecycle guards, trace links | all Manufacturing aggregates | consumed by services and commands | aggregate-local invariants | invariant engine, deterministic utilities | foreign references only | direct service-to-service mutation |
| services | authority-bearing orchestration | one service per domain capability | orchestration, validation, event emission, audit hooks | per aggregate family | depends on domain and contracts | aggregate transactional boundary | lifecycle manager, audit, observation publisher | Product and Inventory ports only | direct query write paths |
| commands | write-side application entry points | command handlers and command contracts | command validation, dispatch, idempotency, authorization | mapped to owning aggregate | depends on services, domain, contracts | command atomicity boundary | service registry, invariant engine | Product/Inventory validators and ports | bypassing service orchestration |
| queries | read-side projection access | read-only query handlers and list/get contracts | projection lookups, filters, sort, tenant isolation | projection boundaries only | depends on projections and domain facts | read-only projection boundary | metrics, observation, health | none beyond validated refs | mutation or command dispatch |
| persistence | canonical state storage and recovery | repository gateways, state serializers | snapshots, append-only history, recovery metadata | per aggregate store | depends on contracts and domain serialization | tenant-partition boundary | file store, persistence coordinator, recovery coordinator | none direct; uses validated reference snapshots | foreign persistence imports |
| runtime | startup, shutdown, recovery, composition | runtime bootstrap, service registration, readiness | wiring, lifecycle, health aggregation, observation startup | whole platform | top-level consumer of all modules | process-level runtime boundary | runtime host, lifecycle manager, service registry, provider registry | product/inventory validators and ports | business logic duplication |
| integration | platform adapters and validator bindings | Product/Inventory/Shared adapter bindings | validator registry, request translators, response normalization | none; adapter-only | consumed by services and runtime | bounded contract boundary | provider registry, common validators, bounded normalization | Product, Inventory, GSP-1001C contracts | direct data-store imports from foreign platforms |
| projections | read models and derived state | query models and projection rebuilders | aggregation, indexing, summary computation | read-only derived state | depends on domain facts and persistence history | recomputable projection boundary | metrics service, observer registry | none | mutation of canonical state |
| health | readiness and diagnostics | health surface and dependency checks | health contributors and state aggregation | platform-level diagnostics | depends on runtime and integration | startup and steady-state diagnostics boundary | health service, observer publisher | Product/Inventory readiness signals | command authority |
| metrics | operational counters and gauges | metric definitions and snapshot emitters | metric accumulation and export | observational only | depends on domain events and projections | metrics boundary only | metrics service | none | authoritative business state |
| audit | immutable command/transition evidence | audit envelope builders and audit queries | audit record assembly and persistence hooks | platform audit trail | depends on services and events | audit boundary | audit service | none | silent mutation or audit suppression |
| traceability | immutable lineage and correlation | trace record builders and lookup helpers | trace graph appenders, validation, recovery checks | append-only trace boundary | depends on domain facts | trace boundary | observation publisher, recovery coordinator | validated foreign refs only | destructive history rewrite |

Substantive module rule:
- every module family above has a distinct Manufacturing responsibility and an explicit boundary; no placeholder-only modules are required.
