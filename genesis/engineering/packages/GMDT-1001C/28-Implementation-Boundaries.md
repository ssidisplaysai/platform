# 28 Implementation Boundaries

Explicitly prohibited:
- Product definition ownership
- Product BOM ownership
- Inventory stock ownership
- direct Inventory balance mutation
- Commerce transaction ownership
- Finance accounting
- CRM authority
- Asset custody
- Document custody
- Knowledge semantic ownership
- HR identity ownership
- Shared business semantics
- Mission Control mutation authority
- AI canonical state
- direct foreign persistence access
- destructive traceability rewrite
- silent last-write-wins
- speculative Shared expansion
- universal serializer use of bounded normalization

Additional runtime boundary rule:
- module responsibility must remain substantive and domain-specific; no empty symmetry modules are required.
