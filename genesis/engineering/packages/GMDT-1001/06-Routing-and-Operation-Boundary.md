# 06 Routing and Operation Boundary

## Routing Ownership Resolution

Product may provide canonical process metadata or routing-definition references as design intent.

Manufacturing owns:
- execution routing instantiation
- routing-step execution state
- operation sequencing at run time
- operation completion and exception facts

## Canonical Ownership Distinction

Product definition routing metadata, where present, remains Product-owned design authority.

Manufacturing execution routing remains Manufacturing-owned run-time execution authority.

This separation avoids duplicate canonical ownership.
