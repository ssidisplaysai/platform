# GIDT-1001-S6

Inventory Platform Slice 6 implementation package for lot, serial, and expiration behavior.

## Scope
- Lot registration and lifecycle.
- Serial registration and lifecycle.
- Lot and serial associations.
- Expiration state evaluation and query surfaces.
- Quarantine and release behavior.
- Optimistic concurrency and idempotency.
- Runtime registration.

## Out of Scope
- Persistence.
- Receiving, put-away, picking, packing, shipment orchestration.
- Reorder policy and supplier workflows.
- APIs, live external integrations, Mission Control routes.
