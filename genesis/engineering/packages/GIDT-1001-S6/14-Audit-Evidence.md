# 14 Audit Evidence

Audit events emitted for:
- lot register accepted/rejected.
- lot status and metadata changes.
- serial register accepted/rejected.
- serial binding and status changes.
- expiration evaluation accepted/rejected.
- stale version and invalid association rejection paths.
- idempotent replay and conflicting idempotency payload rejection.

Audit details include tenant, entity type/id, inventory item, codes, version transitions, idempotency key, and result classification.
