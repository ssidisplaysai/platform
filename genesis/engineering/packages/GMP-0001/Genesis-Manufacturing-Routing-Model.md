# Genesis Manufacturing Routing Model

## Routing Purpose
Routing defines how production executes through ordered operations with explicit dependencies and capability requirements.

## Routing Must Define
1. Operation sequence
2. Required machines
3. Required skills
4. Estimated durations
5. Dependencies

## Routing Governance Rules
1. Operation order is explicit and deterministic.
2. Dependency graph must be acyclic for executable plans.
3. Capability requirements must map to machine and labor qualifications.
4. Duration estimates support schedule and capacity planning.
5. Routing changes are versioned for historical reproducibility.

## Routing Outcomes
1. Repeatable execution planning.
2. Predictable capacity modeling.
3. Auditable production decision context.
