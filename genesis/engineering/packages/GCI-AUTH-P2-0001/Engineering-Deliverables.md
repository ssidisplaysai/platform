# Engineering Deliverables

## Required Implementation Package
- GCI-P2-0001
- Purpose: IBR Runtime implementation package only.

## Required Certification Package
- GCI-CERT-P2-0001
- Purpose: independent constitutional certification evidence and decision record for IBR Runtime.

## Required Freeze Package
- GCI-P2-0001-FREEZE
- Purpose: freeze closeout, drift attestations, and production baseline reference for IBR Runtime.

## Deliverable Completion Rules
- No package can be skipped.
- Certification package must be complete before integration.
- Freeze package must be complete before downstream authorization request.
- Each package must include lifecycle metadata and cross-reference this authorization package.
