# Governance Gates

## Gate 0: Authorization Activation
Entry conditions:
- GCF-1.1 published
- GCI-P2-0000 published
- this package approved

Exit condition:
- implementation package charter opened for IBR only

## Gate 1: Implementation Readiness
Entry conditions:
- dependency plan approved
- boundary controls documented
- test matrix approved

Exit condition:
- implementation may begin for IBR scope only

## Gate 2: Certification Readiness
Entry conditions:
- engineering evidence complete
- required tests executed
- nonconformances dispositioned

Exit condition:
- independent certification review initiated

## Gate 3: Integration Readiness
Entry conditions:
- certification status is CERTIFIED
- no boundary violations open

Exit condition:
- controlled integration workflow authorized

## Gate 4: Freeze Readiness
Entry conditions:
- integrated baseline validated
- drift checks complete

Exit condition:
- runtime freeze package publication
