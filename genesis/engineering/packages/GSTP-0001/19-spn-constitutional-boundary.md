# SPN Constitutional Boundary

## Included in Constitutional Scope
- Terminology
- Role taxonomy
- Lineage distinction principles
- Attribution and ledger constitutional requirements
- Lifecycle model proposals
- Inactivity constitutional principles

## Excluded from Scope
- Implementation of attribution engine
- Implementation of commission engine
- Implementation of ledger storage
- Implementation of payouts
- Implementation of portals/dashboards

## Subordination
SPN constitutional artifacts remain subordinate to GSTP platform constitutional authority and Genesis constitutional authority.
