# Genesis Workflow Integration

## Workflow Boundary
Workflow orchestrates human tasks, approvals, notifications, and automated routing of requests.

## Consumed By Manufacturing
- Workflow orchestration
- Approvals
- Notifications
- Human tasks

## Rules
- Manufacturing may request orchestration, but workflow remains authoritative for task execution.
- Manufacturing does not embed workflow runtime logic.
- Workflow integration is contract-first and deterministic.
