# 01 Slice Scope

Slice 3 delivers the first business foundation for Manufacturing while remaining bounded.

In scope:
- Work Order creation, planning, release control, pause/resume/hold, completion, and closure foundations.
- Production Run and Production Batch creation with tenant and relationship validation.
- Execution-readiness projection and deterministic query access.

Explicitly out of scope:
- Routing and operation execution semantics.
- Persistence and APIs.
- Cross-domain live execution coupling.
