# 02 Entity Model

All entities below are Manufacturing-owned unless explicitly marked as foreign reference entities.

Legend for compactness:
- Tenant: all entities are tenant-scoped and tenant-immutable unless noted
- Version: optimistic version and monotonic increment
- Concurrency: expected-version check plus idempotency key where command-based mutation exists
