# Genesis Commerce Platform Product Site Assignments

## Assignment Contract
Each product-site assignment includes:
1. Target site identity.
2. Enabled state for site-specific availability.
3. Site-specific slug and optional site-specific display metadata.
4. Visibility and feature state.
5. Ordered placement controls.
6. Site-level category references.
7. Site-level publication status.
8. Site-level profile references (seo/prompt/image).
9. Last readiness and publication references.

## Bounded Behavior
1. Assignment enablement participates in readiness checks.
2. Site publication status must be compatible for publish readiness.
3. Disabled or missing assignment blocks readiness.
