# Implementation Principles

## Constitutional Principles
Implementation SHALL follow:
- Architecture First
- Specification Driven
- Test First
- Deterministic
- Replayable
- Auditable
- Immutable
- Versioned
- Conformance Before Optimization
- Certification Before Release
- No Architectural Drift

## Principle Controls
- Every implementation change MUST map to authoritative architecture and GCS-0001 clauses.
- Every phase MUST demonstrate deterministic and replayable behavior before promotion.
- Optimization SHALL NOT alter normative outputs.
