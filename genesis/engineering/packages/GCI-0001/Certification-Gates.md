# Certification Gates

## Gate Sequence
- CG-1: Runtime Foundation Gate
- CG-2: Evidence Runtime Gate
- CG-3: IBR Runtime Gate
- CG-4: Entity Resolution Runtime Gate
- CG-5: Relationship Resolution Runtime Gate
- CG-6: Business Rule Runtime Gate
- CG-7: Assembly Runtime Gate
- CG-8: Compiler Certification Runtime Gate
- CG-9: Production Compiler Gate

## Gate Requirements
Each gate MUST include:
- entry condition evidence
- phase validation evidence
- conformance/replay/determinism results
- manifest validation results
- certification decision rationale

## Blocking Rule
Any unresolved blocking defect or governance exception SHALL block gate approval.
