# Implementation Governance

## Governance Domains
- Implementation Reviews
- Architecture Reviews
- Specification Reviews
- Certification Reviews
- Release Reviews
- Deviation Approval Process
- Exception Handling
- Change Control

## Governance Rules
- All reviews MUST be evidence-backed and recorded.
- Deviation approval MUST be explicit, versioned, and auditable.
- Exception handling MUST classify severity, owner, and closure date.
- Change control MUST include impact analysis on conformance and certification.

## Authority Model
- Implementation Owner: accountable for delivery execution.
- Architecture Owner: accountable for architectural conformance.
- Specification Owner: accountable for GCS-0001 conformance.
- Certification Owner: accountable for gate decision quality.
- Governance Owner: accountable for constitutional compliance.
