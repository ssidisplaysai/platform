# Semantic Graph Model

## Graph Purpose
Represent canonical business meaning as a deterministic graph.

## Graph Components
- nodes: canonical entities
- edges: directional relationships
- attributes: rule outcomes, ownership, confidence, trust, causality
- graph-level lineage and provenance fingerprints

## Graph Invariants
- deterministic node and edge ordering
- directional edge semantics
- versioned graph publication
- replayable graph reconstruction
