# Versioning Strategy

## Versioning Policy
- Semantic artifacts evolve by immutable version publication.
- Active state changes via explicit supersedence.
- Historical versions remain queryable.

## Version Components
- version identity
- prior version reference
- change reason
- effective context
- lineage fingerprint

## Version Invariants
- no in-place mutation
- deterministic version identity
- supersedence chain must remain acyclic and complete
