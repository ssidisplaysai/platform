# Implementation Sequencing

## Sequencing Policy
When separately authorized, implementation should proceed in this order:
1. IBR Runtime
2. Entity Runtime
3. Relationship Runtime
4. Business Rule Runtime
5. Business Genome Assembly Runtime

## Readiness Gates per Runtime
- architecture contract finalized
- dependency boundaries validated
- test strategy defined
- certification criteria fixed
- governance authorization approved

## Constraint
This sequencing document does not grant implementation authority.
