# 15 Capability Ownership Matrix

| Capability Class | Owned By | Not Owned By |
| --- | --- | --- |
| Constitutional/Governance | Foundation Authority + Governance domains | Application teams |
| Registry/Validation/Certification/Publishing | Constitutional Services + Governance authorities | Application teams |
| Knowledge/Semantics/Genome | Genesis semantic and compiler architecture domains | Application teams |
| Runtime/Kernel | Genesis runtime domains | Application teams |
| Security/Identity/Authorization/Compliance | Genesis platform security domains | Application teams |
| Application Business Capabilities | Application and business owners | Genesis platform |

Ownership principle:
- Exactly one primary owner per capability.
