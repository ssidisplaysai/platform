1. Governance chain:
CAP-001 -> CAP-003 -> CAP-005 -> CAP-006 -> CAP-004

2. Knowledge chain:
CAP-009 -> CAP-010 -> CAP-011 -> CAP-013 -> CAP-014

3. Runtime chain:
CAP-016 -> CAP-015 -> CAP-017/CAP-018/CAP-019 -> CAP-028

4. Security chain:
CAP-025 -> CAP-026 -> CAP-024 -> CAP-027

## Relationship Rules
1. Dependencies remain acyclic and directional.
2. Downstream capabilities cannot redefine upstream authority.
3. Application capabilities depend on Genesis capabilities, never the reverse.
