# 24 Next Program Recommendation

## Recommended Next Program
GCAP-0002: Genesis Capability Conformance and Certification Framework.

## Rationale
GCAP-0001 defines what capabilities exist and who owns them. The next highest-value step is a formal conformance framework that enforces these capability boundaries and readiness gates across future Genesis programs.

## Scope of GCAP-0002
1. Capability conformance scoring.
2. Ownership-boundary violation taxonomy.
3. Certification thresholds for new capabilities.
4. Review templates for capability additions and supersession.

## Exclusions
No runtime or application implementation work.
