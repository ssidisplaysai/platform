# 25 Risk Assessment

## Key Risks
1. Capability boundary erosion between Genesis and applications.
2. Hidden overlap between governance and implementation responsibilities.
3. Capability expansion introducing runtime redesign pressure.
4. Ambiguous ownership for security/compliance responsibilities.

## Mitigations
1. Enforce CAP-030 prohibition controls.
2. Require explicit owner and dependency declaration per capability.
3. Apply non-redesign freeze controls for runtime and constitution.
4. Require validation and certification gates for new/changed capabilities.
