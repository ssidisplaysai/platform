# 03 Capability Taxonomy

## Taxonomy Layers

1. Universal Enterprise Capability
- Capabilities transferable across enterprise platforms (for example: validation, lifecycle governance, traceability).

2. Genesis Capability
- Capabilities owned by Genesis constitutional, semantic, compilation, runtime, and operational architecture.

3. Application Capability
- Capabilities delivered by applications consuming Genesis platform contracts.

4. Business Capability
- Domain-specific business competencies owned by enterprise applications and business operators.

## Capability Classifications

### Foundational Capabilities
- Constitutional Governance
- Registry Services
- Artifact Lifecycle
- Enterprise Semantics
- Runtime Platform
- Kernel Services
- Identity
- Authorization

### Supporting Capabilities
- Discovery
- Evidence
- Enterprise Knowledge
- Knowledge Graph
- Enterprise Validation
- Enterprise Certification
- Enterprise Readiness
- Publishing
- Observability
- Operations
- Compliance

### Optional Capabilities
- Workflow Orchestration
- Messaging
- Scheduling
- AI Reasoning
- Automation
- Future Extension Adapters

### Application-Exclusive Capabilities
- Application business rules
- Application business workflows
- Application domain object semantics
- Application user experience semantics

### Capabilities Forbidden Inside Genesis Ownership
- Domain-specific pricing logic
- Domain-specific policy adjudication logic
- Tenant-specific business process ownership
- Application UI behavior design ownership
- Enterprise-specific org/business model ownership
