# Certification Requirements

Independent certification for the later Relationship Runtime implementation must verify:
- deterministic relationship identity;
- repeatable candidate formation;
- immutable relationship records;
- relationship classification determinism;
- directionality and cardinality determinism;
- confidence preservation;
- provenance and lineage preservation;
- replay linkage;
- entity linkage;
- version lineage, supersedence, and retirement;
- registry overwrite semantics and ordering;
- negative-path integrity;
- architecture guardrails;
- Replay, IBR, and Entity regression safety;
- package and catalog integrity;
- clean isolated candidate snapshot.
