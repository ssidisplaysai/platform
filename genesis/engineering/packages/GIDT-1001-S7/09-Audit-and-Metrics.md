# 09 Audit and Metrics

Audit events emitted for reference validation:
- inventory.reference.validation.succeeded
- inventory.reference.validation.failed-mandatory
- inventory.reference.validation.failed-optional
- inventory.reference.validation.missing-validator

Metrics tracked:
- Total validations and failures
- Mandatory and optional failure counts
- Missing-validator count
- Tenant mismatch and stale counts
