# 01 Slice Scope

In scope:
- Centralized typed external reference validation model
- Deterministic validator registry and reference service
- Mandatory product reference validation routed through central service
- Optional external request reference checks for reservation/allocation flows
- Runtime contract token and registration for reference validation service
- Focused S7 tests and regression checks

Out of scope:
- HTTP endpoints
- Persistence layer changes
- Cross-domain API contract negotiation
