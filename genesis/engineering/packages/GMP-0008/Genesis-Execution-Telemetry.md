# Genesis Execution Telemetry

## Telemetry Model
Execution telemetry provides architectural support for runtime metrics and diagnostics.

## Telemetry Dimensions
- Runtime metrics
- Cycle time
- Idle time
- Downtime
- Completion
- Operator events
- Machine events

## Rules
- Telemetry remains implementation-independent.
- Telemetry preserves execution traceability without taking ownership of machines or labor.
