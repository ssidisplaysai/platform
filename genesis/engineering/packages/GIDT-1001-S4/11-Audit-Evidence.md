# 11 Audit Evidence

Implemented audit evidence includes:

1. action
2. tenant
3. entity IDs
4. movement ID
5. ledger entry IDs
6. idempotency key
7. expected versions
8. resulting versions
9. quantity deltas
10. success or rejection classification
11. timestamp
12. correlation metadata

Implemented audit event classes include:

1. accepted movement
2. rejected movement
3. accepted adjustment
4. rejected adjustment
5. duplicate idempotent replay
6. conflicting idempotency reuse
7. stale-version rejection
8. insufficient-stock rejection
9. ledger-integrity rejection
