# 02 Knowledge vs Document Boundary Charter

Constitutional purpose:

- Permanently define Knowledge and Document ownership boundaries.
- Prevent duplicate ownership.

Knowledge owns:

- Knowledge semantics
- Knowledge categorization and tagging
- Knowledge graph relationships
- Knowledge publication state as knowledge-domain state
- Knowledge lifecycle as knowledge-domain state
- Knowledge-level curation and discoverability semantics

Document owns:

- Document artifact custody
- Document storage and persistence semantics
- Document revision authority
- Document template/rendering lifecycle
- Document-level approval/signature state as document-domain behavior

Shared interactions:

- Knowledge may reference Document identifiers through contract-defined references.
- Documents may be evidence or source artifacts for knowledge entities.
- Cross-domain linkage is relationship-driven and contract-governed.

Consumer-only relationships:

- Knowledge consumes Document contracts.
- Knowledge never bypasses Document contracts.
- Knowledge never assumes Document ownership semantics.

Non-duplication rule:

- If a concept concerns artifact custody or revision authority, Document owns it.
- If a concept concerns semantic meaning, categorization, or knowledge graph context, Knowledge owns it.
