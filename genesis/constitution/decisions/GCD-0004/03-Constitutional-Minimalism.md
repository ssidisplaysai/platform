# 03 Constitutional Minimalism

Governing philosophy:

- Constitutional minimalism is adopted for Enterprise Expansion Era governance.

Core principles:

1. Burden of proof rests on constitutional expansion.
2. Existing constitutional authority must be reused whenever reasonably possible.
3. New constitutional standards are exceptional, not routine.
4. Enterprise capability implementation is the primary constitutional objective.

Creation threshold for new constitutional standards:

- New constitutional standards may be created only when both criteria are true:
1. A demonstrated architectural deficiency exists.
2. The deficiency cannot be resolved through interpretation, clarification, existing standards, implementation guidance, or reusable engineering patterns.

Preferred remediation order before expansion:

1. Reuse
2. Clarification
3. Interpretation
4. Pattern extraction
5. Constitutional expansion only when all prior options are insufficient

Governance implication:

- Constitutional evolution remains allowed, but now requires exceptional justification discipline.
