# 11 Release Handoff Standard

Certification must deliver the following before release may begin:

- Independent certification package complete
- Final decision issued
- Condition status explicit
- Certification validation report complete
- Completion record complete

Release governance requirements:

- Release packages are documentation-only.
- No implementation changes are permitted during release packaging.
- Release lineage must reference certified anchors only.

Release handoff rule:

- Release work may not begin without completed certification evidence.
