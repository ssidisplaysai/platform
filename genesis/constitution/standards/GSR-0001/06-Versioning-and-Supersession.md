# 06 Versioning and Supersession

Versioning policy:

1. Constitutional baselines
- Major.Minor versioning is used when family conventions require semantic release form.

2. Identifier-lineage families
- Families using numeric plus optional suffix lineage preserve stable baseline identity and append successors.

3. Decision immutability
- Constitutional decisions are immutable per identifier; change requires new decision identifier.

Supersession rules:

1. One active authority per subject
- At any point, exactly one standard is active authoritative for a given normative subject.

2. Explicit supersession statement required
- Successor standards must explicitly identify superseded standards.

3. Bidirectional traceability required
- Superseded standard must reference successor.
- Successor must reference predecessor and migration intent.

4. No silent supersession
- Authority replacement without explicit supersession metadata is invalid.

5. Derivative alignment
- Derivative artifacts must update references to the active authoritative standard.

Supersession evidence requirements:

1. Rationale for change.
2. Scope delta summary.
3. Compatibility and governance impact statement.
4. Approval decision record.

Preservation requirements:

- Superseded standards remain immutable, addressable, and auditable.
