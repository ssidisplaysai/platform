# 02 Shared Patterns and Governance Conventions

Shared architectural and governance conventions:

- Uniform package structure per platform dossier.
- Explicit ownership matrix with non-ownership declarations for every platform.
- Boundary matrix using consumer-only interactions.
- Dependency matrix partitioned into required, optional, and forbidden sets.
- External contract catalog with conceptual interfaces only.
- Mission Control and AI sections with permanent non-ownership guarantees.
- Certification strategy pre-aligned with GEP-0001 and release lifecycle.
- Operational readiness criteria documented before engineering begins.

Cross-platform coherence objective:

- The Phase II portfolio shall evolve as one governed enterprise operating system, not a collection of isolated systems.
