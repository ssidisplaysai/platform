# 08 Domain Model

Canonical conceptual entities:

- Primary capability entity set aligned to Financial Control, Ledger Semantics, and Compliance Governance
- Category and classification entities
- Relationship entities
- Lifecycle state entities
- Governance and approval entities
- Evidence and source-reference entities

Domain model constraints:

- One canonical owner per concept.
- External references are contract identifiers only.
- No duplicate enterprise ownership.
