# 09 Ownership Matrix

Owned by Inventory Platform:

- Inventory Units, Stock State, Location Allocation Semantics, Movement Records, Availability Semantics

Consumed from other platforms:

- Identity, Authentication, Authorization, Organization, Product, Workflow, Messaging
- Optional: Scheduling, Notification, Asset, AI Orchestration, Mission Control, Analytics

Explicitly NOT owned:

- Commerce order ownership, Manufacturing process ownership, Finance ledger ownership

Ownership assertion:

- Every concept in this platform dossier has exactly one canonical owner.
