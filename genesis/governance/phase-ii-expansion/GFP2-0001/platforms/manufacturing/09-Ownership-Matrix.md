# 09 Ownership Matrix

Owned by Manufacturing Platform:

- Production Plans, Work Instructions Semantics, Manufacturing Execution States, Process Traceability

Consumed from other platforms:

- Identity, Authentication, Authorization, Organization, Product, Inventory, Workflow, Asset, Messaging
- Optional: Scheduling, Notification, AI Orchestration, Analytics, Mission Control, Document

Explicitly NOT owned:

- Inventory ownership, Product definition ownership, Finance cost-account ownership

Ownership assertion:

- Every concept in this platform dossier has exactly one canonical owner.
