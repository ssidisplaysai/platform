# Dashboard Model

Work Order: GMC-1001
Date: 2026-07-30

## Dashboard Inputs

- discovered application list
- enriched health states from EHC
- compatibility status
- capability summaries

## Dashboard Metrics

- total applications
- health-state distribution
- readiness distribution
- compatibility distribution
- capability declared/available/unavailable counts

## Constraint

Mission Control dashboard performs no health calculations beyond rendering supplied EHC states and counting distributions.
