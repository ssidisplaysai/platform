# Launcher Model

Work Order: GMC-1001
Date: 2026-07-30

## Launch Resolution

Launch metadata is resolved from Registry discovery metadata:
- launchPath
- optional baseUrl

## Supported Targets

- INTERNAL route launch
- EXTERNAL URL launch
- FUTURE_DESKTOP (future-ready)
- FUTURE_MOBILE (future-ready)
- FUTURE_DEEP_LINK (future-ready)

## Constraint

Launch behavior is metadata-driven and contains no application-specific branching.
