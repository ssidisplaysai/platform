# EAR-0007 Registry Governance Rules

Artifact ID: EAR-0007
Decision Parent: GCD-0004
Status: CERTIFIED
Lifecycle State: Published
Authority: Genesis Governance Authority

## Governance Rules

1. Single registry authority SHALL be maintained at all times.
2. Constitutional Registry and Enterprise Application Registry SHALL remain separate by constitutional boundary.
3. Registry mutations require approval when lifecycle or ownership class changes.
4. Registry changes require immutable audit records.
5. Governance reviews SHALL validate compatibility with GCD-0003 boundaries.
6. Kernel authority boundaries from GACD-0006 SHALL remain unchanged.
7. Registry authority doctrine from GACD-0005 SHALL remain unchanged.
8. Changes to schema-required fields require constitutional review before activation.

## Compliance Triggers

- authority owner changes
- lifecycle policy changes
- dependency model changes
- compatibility rule changes
- permission governance changes

## Non-Compliance Disposition

- Block publication of invalid governance mutations.
- Require remediation plan and reassessment package.
