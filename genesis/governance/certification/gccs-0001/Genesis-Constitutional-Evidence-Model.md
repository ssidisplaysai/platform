# Genesis Constitutional Evidence Model

## Admissible Evidence Classes
- PRIMARY: Direct, authoritative artifacts (constitutional docs, approved standards, canonical manifests, immutable records)
- SECONDARY: Supporting artifacts (derived reports, summarized analyses)
- CONTEXTUAL: Informative artifacts used for interpretation context

## Confidence Levels
- Low
- Medium
- High
- Verified
- Deterministic

## Evidence Quality Dimensions
- Authenticity
- Integrity
- Completeness
- Timeliness
- Reproducibility
- Traceability

## Evidence Hierarchy and Precedence
1. PRIMARY deterministic evidence
2. PRIMARY verified evidence
3. PRIMARY high confidence evidence
4. SECONDARY high/verified evidence
5. CONTEXTUAL evidence

## Conflicting Evidence Resolution
1. Prefer higher-precedence class.
2. Prefer newer non-superseded evidence with intact traceability.
3. If unresolved, set INSUFFICIENT EVIDENCE and defer decision.

## Insufficient, Unverifiable, Obsolete, and Superseded Evidence
- Insufficient: Missing required class or confidence threshold.
- Unverifiable: Fails authenticity/integrity checks.
- Obsolete: Outdated relative to active clause/version window.
- Superseded: Replaced by successor evidence lineage.
