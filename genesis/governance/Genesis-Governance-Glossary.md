# Genesis Governance Glossary

## Core Terms
- Constitution: Highest authority document for Genesis governance.
- Governance Library: Permanent standards and procedure authority below the Constitution.
- Standard: Normative rule defining required behavior or quality constraints.
- Procedure: Ordered governance process implementing a standard.
- Implementation: Code or operational action that executes procedure requirements.
- Evidence: Verifiable artifacts proving implementation outcomes.
- Certification: Formal decision asserting conformance against standards.
- Audit: Structured assessment of conformance, traceability, determinism, and mutation safety.
- Supersession: Controlled replacement of one governance artifact by another.
- Successor: New governance artifact replacing an existing active artifact.
