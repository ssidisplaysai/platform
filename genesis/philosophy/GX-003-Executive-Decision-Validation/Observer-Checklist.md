# Observer Checklist

Program: GX-003 Executive Decision Validation  
Version: v1.0

Use this checklist for each participant and each scenario.

## Session Setup
- Participant identity code assigned
- Scenario order confirmed
- TTU sheet prepared
- Findings template prepared
- Improvement log open

## During Scenario
- TTU start timestamp captured
- Participant answers monitored against five TTU criteria
- TTU stop timestamp captured only after confidence confirmation
- Observer notes include direct participant language
- No moderator coaching observed

## Understanding Quality
- Participant described enterprise health clearly
- Participant identified what changed
- Participant identified what requires attention
- Participant proposed clear next action
- Participant confidence was explicit

## Explanation Trust
- Participant cited supporting evidence
- Participant reported trust in explanation
- Participant understood why recommendation was made

## Confusion Signals
- Hesitation longer than 20 seconds at key moments
- Contradictory interpretations voiced
- Recommendation uncertainty voiced
- Search path confusion observed

## Post-Scenario Completion
- Standard five validation questions asked
- Questionnaire completed
- Findings template completed
- Improvement opportunities logged

## End of Session
- All scenarios complete
- TTU records complete
- Consolidated observer summary recorded
- Priority improvement candidates tagged
