# Engineering Quality Baseline

## Baseline Definition

Release 1.1 engineering quality baseline is established by GQI-0001 and validated by GQI-0002 closure evidence.

## Canonical Standards

1. Deterministic script-first quality gates.
2. Certification-grade validation reproducibility.
3. CI execution parity with local package scripts.
4. Scope-isolated remediation and evidence publication.

## Baseline Commands

- npm run typecheck
- npm run typecheck:templates
- npm run lint:quality-gate
- npm run test:template-validation
- npm run test:quality-regression
- npm run quality:ci

## Baseline Status

Engineering quality controls are operational and release-suitable.
