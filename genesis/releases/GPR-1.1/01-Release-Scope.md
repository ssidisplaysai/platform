# Release Scope

## In-Scope

1. Certified identity capabilities required for baseline operation.
2. Certified governance baseline required for platform control and freeze policy.
3. Engineering/repository quality baseline required for deterministic future development.
4. Architecture baseline records supporting current certified capability set.

## Out-of-Scope

1. New runtime behavior.
2. New module implementation.
3. Architecture redesign.
4. Any work not already certified or explicitly baseline-approved.

## Inclusion Rule

Only capabilities and artifacts with completed certification or approved baseline disposition are included.

## Exclusion Rule

Experimental, partially certified, or uncertified implementation work is excluded from Release 1.1.
