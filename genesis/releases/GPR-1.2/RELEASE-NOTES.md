# GPR-1.2 Release Notes

## Release Summary

Genesis Platform Release 1.2 publishes the second certified platform baseline and adds Messaging as a fully certified platform capability.

## What Changed from GPR-1.1

1. Messaging upgraded from non-baseline capability to certified baseline inclusion through GMP-1001C.
2. Certified capability catalog updated to include four certified baseline families.
3. Hall of releases updated with GPR-1.2 supersession and lineage.
4. Compatibility and dependency-chain records refreshed for the new baseline.

## Baseline Capability Set

1. Authentication (GID-1002C)
2. Authorization (GID-1003C)
3. Messaging (GMP-1001C)
4. Repository Quality (GQI-0002)

## Validation Highlights

1. Canonical typecheck passing.
2. Template validation passing.
3. quality:ci passing.
4. Regression passing.

## Constraints Confirmed

No runtime implementation changes were introduced as part of this release publication work order.
