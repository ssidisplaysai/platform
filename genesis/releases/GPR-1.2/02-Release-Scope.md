# Release Scope

## In Scope

1. Publication of the certified Genesis platform baseline at version 1.2.0.
2. Inclusion of certified Authentication, Authorization, Messaging, and Repository Quality capabilities.
3. Publication of governance, architecture, compatibility, and readiness baseline records.
4. Publication of release lineage, dependency chain, and release hall updates.

## Out of Scope

1. Runtime implementation changes.
2. New feature development.
3. Architecture redesign or expansion.
4. Workflow, notifications, or AI orchestration initiatives.

## Inclusion Rule

Only already-certified capabilities and release-governed baselines are included.

## Exclusion Rule

Any partially certified, uncertified, or experimental capability is excluded from GPR-1.2 baseline declaration.
