# 04 Architecture Baseline

GPR-1.7 architecture baseline extends GPR-1.6 by including the certified Organization Platform.

Organization Platform baseline properties:
- Provider-neutral
- Business-object root
- Tenant-aware
- Hierarchy-aware
- Workflow-neutral
- Scheduling-neutral
- Messaging-neutral
- Notification-neutral
- AI-neutral
- Mission Control compatible

Architecture status:
- Baseline architecture remains certified and stable.
- No architecture redesign or capability ownership expansion is introduced by this release.
