# Release Scope

## Scope Boundary
This record documents only capabilities verified as present in Genesis Enterprise OS v0.1.0.

## Included Capabilities
1. Genesis platform shell.
2. GLW entry point at /glw.
3. GLW pages route at /glw/pages.
4. Production runtime operation via Next.js production server contract.
5. Public routing through https://app.ssiai.app.
6. Governed release process execution and evidence capture.
7. Dedicated production worktree for operational deployment.
8. Deterministic production build behavior from clean state.

## Excluded From Scope
1. New capabilities not implemented or verified in this release.
2. Architectural redesign.
3. Runtime code change after certified release commit.
