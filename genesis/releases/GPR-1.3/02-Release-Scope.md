# Release Scope

## In Scope

1. Publish certified baseline documentation for GPR-1.3.
2. Update release lineage and hall of releases.
3. Update certified capability inventory and dependency graph.
4. Publish release certificate and release notes.

## Out of Scope

1. Production code changes.
2. Engineering package changes.
3. New certification work.
4. New platform capability implementation.

## Scope Guardrails

1. Only files under genesis/releases/GPR-1.3 may be committed.
2. No src, tests, or runtime files may be modified.
3. No files under genesis/engineering/packages may be modified.
4. No files under genesis/certification/packages may be modified.
